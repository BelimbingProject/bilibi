# fastText lid.176 attribution

The separately provisioned, unmodified `lid.176.bin` language identification model is by the fastText authors at Facebook Research, distributed under the [Creative Commons Attribution-ShareAlike 3.0 Unported license](https://creativecommons.org/licenses/by-sa/3.0/).

Source and supported languages: <https://fasttext.cc/docs/en/language-identification.html>. The training data comes from Wikipedia, Tatoeba and SETimes. Bilibi's asset version is `lid.176-bin-v1`; the model is unchanged. Keep this attribution and license link with redistributed copies. Distributing adaptations of the model requires attribution, an indication of changes and the applicable ShareAlike license; the model's license is separate from the Rust code's MIT license.

The model authors request citations of:

- Armand Joulin, Edouard Grave, Piotr Bojanowski and Tomas Mikolov, [Bag of Tricks for Efficient Text Classification](https://arxiv.org/abs/1607.01759), 2016.
- Armand Joulin, Edouard Grave, Piotr Bojanowski, Matthijs Douze, Hervé Jégou and Tomas Mikolov, [FastText.zip: Compressing text classification models](https://arxiv.org/abs/1612.03651), 2016.
